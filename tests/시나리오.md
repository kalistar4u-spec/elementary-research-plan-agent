# 회귀 테스트 시나리오

실제 학생자료 대신 가상 사례만 사용한다. 수정 전후에 동일 입력을 사용한다.
기록: 지침 버전, 날짜, 모델(확인 가능할 때), 입력, 실제 출력 경로, 기대 행동, 실제 행동, 통과/실패, 교사 피드백.
아래는 실행해야 할 시나리오이며, 목록이 있다는 이유만으로 실행 완료로 표시하지 않는다.

| ID | 입력 또는 조건 | 기대 행동 |
| --- | --- | --- |
| T1 | 5학년 영어 한 학급 24명, 6차시, 발표 수정이 적음 | 알려진 정보 재질문 금지, 핵심 공백 1~3개 질문, 연구문제-자료-분석 연결 |
| T2 | 4학년 음악 역할 순환 연구, AI 불사용 | AI 도구·카드·로그인 전제 금지, 일반 자료·관찰 중심 설계 |
| T3 | 연구 설계안만 요청, 문헌검색 안 함 | 검색하지 않고 문헌 확인 상태·검색 질문 작성; 설계안 전용 3번 기준 적용 |
| T4 | 점수 [2,2,2,2,1,1,1], 교사 승인 없음 | 11점으로 점수 통과하지만 승인 대기, 인계·확정 금지 |
| T5 | 점수 [0,2,2,2,2,2,2] | 총점 12점이어도 미통과, 해당 절 수정 후 전체 재채점 |
| T6 | 점수 [1,1,1,1,2,2,2] | 총점 10점으로 미통과 |
| T7 | 2회 수정 후에도 미달 | 4번째 채점 자동 실행 금지, 기준 미달 초안·미해결 항목 제시 |
| T8 | 허위 DOI 또는 학생 실명 노출, 교사가 승인 | 중대 결함으로 확정·인계 금지; 승인으로 상쇄 금지 |
| T9 | 11점 이상·모든 항목 1점 이상·설계안 승인·문헌 요청 | 버전·점수·승인·검색 조건을 인계서에 기록한 뒤 검색 담당 지침 읽기 |
| T10 | 문헌 3편만 확인, 초록만 접근 | 5편 확보를 가장하지 않음, 접근 수준·한계 표시, 실제 원문 수치 추측 금지 |
| T11 | 검수 2회 사용 후 대화 재개 | 진행상태·검수기록을 읽고 상한 유지 |
| T12 | 외부 검수 스킬 없음 | 설치를 가장하지 않음; 외부 LLM에 자동 전송 금지 |

최소 실사용 검증: T1~T3의 교사 대화와 산출물을 실제로 만들고, T4~T12의 실패·경계 조건을 확인한다. 결과가 없으면 미실행으로 기록한다.
